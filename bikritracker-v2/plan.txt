## Stack Decision

**Frontend:** Next.js — better than plain React here because of API routes (we can proxy FastAPI calls without exposing the backend URL to the client), SSR for the dashboard, and easier deployment.

**Backend:** FastAPI — stays for ML predictions.

**Database:** Firebase Firestore — real-time sync, works perfectly for a single grocery store owner who might use phone + laptop simultaneously. No separate DB server to manage.

**Auth:** Firebase Authentication (email/password).

**ML Strategy:** Instead of a static `.joblib` file, every time a user adds/updates sales history in Firestore, the backend fetches their actual data from Firestore and retrains a lightweight per-user model (Random Forest with scikit-learn). This means predictions improve as the user enters more data. Model gets cached server-side per user.

**Voice:** Web Speech API — completely free, built into Chrome/Edge/Safari.

**QR:** `html5-qrcode` library — free, handles both device camera scanning of barcodes (EAN-13, QR codes) and custom QR codes. For existing product barcodes, we call Open Food Facts API (free) to fetch product name/category.

## Firestore Data Model

```
users/{userId}/
    profile: { name, storeName, city, createdAt }

users/{userId}/products/{productId}/
    { name, category, subcategory, price, city, region, createdAt, updatedAt }

users/{userId}/products/{productId}/history/{historyId}/
    { orderDate, sales, createdAt }

users/{userId}/predictions/{predictionId}/
    { productId, productName, predictionDate, predicted, actual,
      accuracy, lowerBound, upperBound, modelVersion, createdAt }
```

## Page-by-Page Plan

**Login / Signup** — Clean centered card. Email + password. Firebase Auth. Redirect to dashboard on success.

**Dashboard (/)** — 4 stat cards at top (total products, total predictions, avg accuracy, last prediction). Sales trend chart using real Firestore data aggregated across all products. Top 5 products bar chart. Recent predictions list.

**Inventory (/inventory)** — Product list with list/card toggle. Add button opens `ProductModal`. Inside the modal header there are 2 icon buttons: camera (QR) and mic (voice). QR scanner opens a camera overlay, scans barcode → calls Open Food Facts API to prefill name/category, or decodes a custom JSON QR. Voice button activates mic and maps spoken text to whichever field is currently focused. Sales history is editable inline in the modal.

**Predict (/predict)** — Product dropdown + date selector. Predict button calls FastAPI. Result card shows predicted value, range, estimated units. Below that, accuracy chart and predictions history table with "Set Actual" action.
